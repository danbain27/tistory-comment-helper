# 티스토리 교류 도우미

내 키워드와 비슷한 티스토리 블로그 글을 찾아 추천해 주는 도구입니다.
**댓글 자동 등록 기능은 없습니다.** 발견과 초안 준비만 돕고, 댓글은 사람이 직접 답니다.

## 설치 (처음 1번)

```
python -m pip install -r requirements.txt
```

## 앱으로 쓰기 (키·API 불필요)

1. 서버 실행 — 폴더에서 **`py app.py`** (⚠️ `python`이 아니라 `py`)
   → 브라우저가 자동으로 http://127.0.0.1:5000 열림
2. 검색창에 키워드를 넣고 **검색** → 조건에 맞는 서로 다른 블로그 글 10개 추천
3. **[📋 결과 전체 복사]** 버튼 → Claude 채팅에 붙여넣기 → 글마다 댓글 초안을 받음
4. 초안을 참고해 **본인이 직접** 각 블로그에 방문해 댓글 작성

- 각 카드의 **[블로그 열기]** 로 글을 직접 확인할 수 있습니다.
- “매일 새 글 모드”가 켜져 있으면 이전에 찾은 글은 빼고 **매일 다른 10개**가 나옵니다.
- 검색 결과는 `reports/날짜.md`로도 자동 저장됩니다(파일째 Claude에게 줘도 됨).

> **왜 `python`이 아니라 `py`?** 이 PC엔 파이썬이 여러 개라 `python`은 flask 없는
> 스토어 파이썬을 가리켜 실패합니다. `py`는 flask가 있는 파이썬으로 갑니다.

## 명령줄로도 쓰기 (선택)

```
python collect.py        # 기본 10개
python collect.py 5      # 5개만
```

## 설정 (collect.py 상단)

- `KEYWORDS` : 검색할 키워드 목록 (현재: 건프라/프라모델 + 게임 리뷰·공략·슈로대·스팀·스위치·PS5·RPG)
- `TARGET_COUNT` : 하루 수집할 **서로 다른 블로그** 수 (기본 10)
- `WITHIN_DAYS` : 최근 며칠 이내 발행 글만 (기본 31 = 한 달)
- `ONE_PER_BLOG` : 같은 블로그는 하루 1개까지만
- `MIN_DELAY`/`MAX_DELAY` : 요청 사이 예의상 대기 시간

### 자동 제외 필터 (매일 걸러짐)

- **광고/제휴글** (`FILTER_ADS`) — 제목의 `최저가·가격비교·구매가이드·내돈내산·추천 TOP` 등,
  본문의 `쿠팡 파트너스·네이버 쇼핑 커넥트·수수료 제공` 고지문, 쿠팡·스마트스토어 등 쇼핑 링크
- **내 블로그** (`OWN_BLOGS`) — 현재 `danbain.tistory.com` 제외
- **주제 무관 글** (`REQUIRE_RELEVANCE`) — 건프라·게임 등 관련 단어가 하나도 없으면 제외
  (오검색·개인정보처리방침 같은 페이지 걸러냄)
- **발행일** — 검색 단계(최근 1개월) + 본문 발행일 확인 이중 필터. 날짜를 못 읽으면 제외
- **본문 150자 미만**, 카테고리·태그·홈 URL 제외

> 광고글로 오판되면 `AD_TITLE_MARKERS`에서 해당 단어를 빼고,
> 걸러야 할 광고 단어가 있으면 거기에 추가하면 됩니다.

## 파일

- `reports/` : 날짜별 수집 리포트 (댓글 초안 뽑을 때 사용)
- `history.json` : 이미 뽑은 글 기록 (다음 실행 때 새 블로그 위주로 나옴)

## 원칙

- 글을 실제로 읽고 내용에 맞는 진심 댓글만 남기기 (복붙 홍보성 X)
- 한 번에 몰아서 돌리지 말고 하루 10개 선에서
- 상대가 부담스러워하면 즉시 중단
